## 1. 인증 (Auth)

### 1-1. 회원가입
- [ ] `/register`에서 신규 이메일로 가입 (예: `test-w6@example.com`)
- [ ] 비밀번호 규칙(8자+대/소/숫자/특수) 미충족 시 에러 표시
- [ ] 이미 가입된 이메일 → "이미 사용 중" 에러
- [ ] 가입 성공 → 로그인 화면 이동

### 1-2. 로그인
- [ ] 잘못된 비밀번호 → "이메일 또는 비밀번호가 올바르지 않습니다"
- [ ] 정상 로그인 → 상품 목록으로 이동, 우측 상단 MY 표시
- [ ] 개발자도구 → Application → Cookies에 **refreshToken (HttpOnly)** 존재
- [ ] localStorage에 accessToken **없음** (메모리 전용 확인)

### 1-3. 세션 유지 (새 탭/새로고침)
- [ ] 로그인 상태에서 **F5 새로고침** → 로그인 유지됨
- [ ] **새 탭**으로 사이트 열기 → 로그인 유지됨 (refresh 쿠키로 복원)

### 1-4. 로그아웃
- [ ] MY 드롭다운 → 로그아웃 → 로그인 화면 이동
- [ ] 쿠키의 refreshToken 삭제됨

---

## 2. 상품 조회 (비로그인 가능)

- [ ] 로그아웃 상태로 `/products` 상품 목록 표시
- [ ] 페이지당 10개/20개 전환 동작
- [ ] 상품명 검색 동작
- [ ] 상품 클릭 → 상세 페이지 (이미지·가격·재고)

---

## 3. 장바구니 (게스트 + 로그인)

### 3-1. 게스트 장바구니
- [ ] 비로그인 상태로 상품 장바구니 담기 → 헤더 뱃지 수량 증가
- [ ] 장바구니 페이지에서 수량 변경·삭제 동작
- [ ] 새로고침해도 장바구니 유지 (guestId 쿠키 기반)

### 3-2. 로그인 시 병합
- [ ] 게스트 장바구니에 상품 담은 채 로그인 → 사용자 장바구니로 **병합**됨
- [ ] 병합 후 guestId 쿠키 삭제 확인

---

## 4. 주문 (USER)

### 4-1. 주문 생성
- [ ] 장바구니 → 주문 페이지 → 수령인·연락처·배송지 입력
- [ ] 필수값 누락 시 "모두 입력해주세요" 에러
- [ ] 주문 확정 → 주문 완료, 주문 내역으로 이동

### 4-2. 재고 차감 확인 (Saga)
- [ ] 주문 전 상품 재고 메모 → 주문 후 **수량만큼 차감** 확인
  - DB 확인: `SELECT stock FROM product WHERE id=<상품id>;`
  - ※ 화면 재고는 Redis 캐시(10분)라 즉시 반영 안 될 수 있음 → DB로 확인

### 4-3. 내 주문 내역
- [ ] MY → 내 주문 → 주문 목록 표시
- [ ] 상태 뱃지(결제 대기/주문 확정/취소됨) 정상 표시
- [ ] 상품·수량·금액 정확

---

## 5. 판매자 전환 (USER → SELLER)

- [ ] MY → 내 정보 → "판매자 신청" 섹션 표시 (USER만)
- [ ] 전화번호 입력 → "인증하기" → "테스트 서버입니다. 인증되었습니다."
- [ ] 프로필에 🏪 판매자 배지 표시
- [ ] 상단에 **상품관리·주문관리** 메뉴 등장 (재로그인 불필요)

---

## 6. 판매자 상품 관리 (SELLER)

### 6-1. 상품 등록
- [ ] 상품관리 → "+ 상품 등록"
- [ ] **이미지 파일 선택** → 업로드 후 미리보기 표시 (MinIO 저장)
- [ ] 가격에 음수 입력 시도 → 0으로 교정 / 1원 미만 제출 시 에러
- [ ] 재고 음수 차단
- [ ] 카테고리 선택 + 등록 → 목록에 추가됨
- [ ] 공개 상품 목록(`/products`)에도 노출 확인

### 6-2. 상품 수정/삭제
- [ ] 본인 상품 수정 → 반영 확인
- [ ] 본인 상품 삭제 → 목록에서 제거

### 6-3. 권한 격리
- [ ] (가능하면 다른 판매자 상품에 대해) 본인 것만 보이고 수정/삭제 가능

---

## 7. 관리자 상품 관리 (ADMIN)

> admin@ecommerce.com 으로 로그인

- [ ] 관리자 메뉴 → 상품 관리(전체): 모든 상품 표시
- [ ] 각 상품에 **판매자 정보(이름·이메일)** 표시, 플랫폼 상품은 "플랫폼(관리자)"
- [ ] ADMIN 화면 버튼은 **수정/삭제가 아닌 판매 금지/재개**

### 7-1. 판매 금지 (BAN)
- [ ] 특정 상품 "판매 금지" → "판매 금지됨" 배지
- [ ] **공개 목록(`/products`)에서 사라짐** (비로그인/일반 사용자 새로고침 확인)
- [ ] 금지 상품 상세 직접 접근 시 표시 안 됨(404)
- [ ] 금지 상품 주문 시도 → 차단됨
- [ ] ADMIN이 공개 목록을 봐도 금지 상품 **노출 안 됨** (관리자 화면에서만 보임)

### 7-2. 판매 재개
- [ ] "판매 재개" → 공개 목록에 다시 노출

---

## 8. 주문 관리 + 항목 취소 (ADMIN/SELLER)

### 8-1. 조회
- [ ] ADMIN 주문관리: 전체 주문 + 항목별 판매자 표시
- [ ] SELLER 주문관리: **본인 상품이 포함된 주문만**, 본인 항목만 노출
- [ ] 한 주문에 여러 판매자 섞였을 때 SELLER에게 타 판매자 항목 **안 보임**

### 8-2. 항목 취소 (사유 필수)
- [ ] 항목 "취소" → 사유 모달 → 사유 없이 확정 시 에러
- [ ] 사유 입력 후 취소 → 항목 취소선 + 사유 표시
- [ ] 일부만 취소 → 주문 상태 **부분 취소**, 전부 취소 → **취소됨**
- [ ] 합계가 살아있는 항목 기준으로 재계산됨
- [ ] SELLER가 타 판매자 항목 취소 시도 → 거부(403)

### 8-3. 재고 복구 확인 (Saga)
- [ ] 항목 취소 후 해당 상품 재고 **복구(+수량)** 확인
  - DB 확인: `SELECT stock FROM product WHERE id=<상품id>;`
- [ ] **차감↔복구 정합성**: 주문(차감)→취소(복구) 후 원래 재고로 돌아옴

---

## 9. 비밀번호 / 보안

- [ ] MY → 비밀번호 변경 → 변경 후 자동 로그아웃 → 새 비번으로 로그인
- [ ] 401 응답 시 자동으로 로그인 페이지 이동 + "세션 만료" 안내
- [ ] 비로그인으로 `/order`, `/orders`, `/admin` 접근 → 로그인/홈으로 리다이렉트
- [ ] USER 권한으로 `/admin` 접근 → 홈으로 리다이렉트

---

## 10. 엣지 케이스

- [ ] 재고보다 많은 수량 주문 → 재고 부족으로 주문 취소(보상 트랜잭션), 재고 변동 없음
- [ ] 수량 1000 이상 장바구니 입력 → 서버 400
- [ ] 잘못된 guestId 쿠키 위조 → 무시됨 (정상 동작)
- [ ] 새 탭에서 동시 로그인/주문 → 세션·장바구니 정상
