## 검증 한계 (정직 기록)
- **UI 승인/거부 버튼 클릭**: 내장 브라우저 자동 클릭이 일부 버튼의 React onClick을 트리거하지 못해(기존 스윕에서도 동일 현상) API로 대체 실행. **버튼 렌더·결과 반영은 화면으로 확인**했으나 "버튼 클릭 자체"는 미검증 → 실제 크롬 육안 확인 권장.
- **거부(reject) 플로우**: 이번 세션 미검증(➖). 승인 경로만 실행.
- 반품 기한·부분 수량 반품은 설계상 범위 외.

## 결론
반품·환불의 **자격 판정 → 신청 → 관리자 승인 → 재고 복구 → 상태 전이 → 알림 → 양쪽 화면 반영**이 실 서버에서 정상 동작. Flyway V9도 실 DB 적용 확인. 차단 이슈 없음.
