# 배포 체크리스트 (운영 환경)

운영(prod) 배포 전 반드시 확인해야 하는 보안·설정 항목입니다.
각 항목은 배포 담당자가 직접 확인 후 체크(`[x]`)합니다. 초보자도 이해할 수 있도록 이유를 함께 적었습니다.

---

## 1. 서비스 포트 내부망 전용 바인딩 (M-N5)

- [ ] auth-service(8081) 외부 미노출 — 내부망(사설 IP/컨테이너 네트워크)에서만 접근
- [ ] product-service(8082) 외부 미노출
- [ ] order-service(8083) 외부 미노출
- [ ] monitoring-service(8084) 외부 미노출
- [ ] 게이트웨이(8080)만 외부에 공개

> **이유**: 각 서비스는 게이트웨이가 넣어준 `X-User-Id` / `X-User-Role` 헤더를 그대로 믿고 인가를 판단합니다.
> 서비스 포트가 외부에 직접 열려 있으면, 공격자가 `X-User-Role: ADMIN` 헤더를 위조해 보내는 것만으로
> 관리자 권한을 얻어 인가를 우회할 수 있습니다. 따라서 인증/헤더 주입을 담당하는 게이트웨이(8080)만
> 외부에 노출하고, 나머지 서비스는 방화벽/보안그룹/네트워크 정책으로 내부망에서만 접근 가능하게 막습니다.

---

## 2. INTERNAL_TOKEN 환경변수 (M-N1)

- [ ] `INTERNAL_TOKEN` 환경변수를 운영에서 반드시 설정 (dev 기본값 사용 금지)
- [ ] auth-service 와 product-service 가 **동일한 값**을 사용하도록 동기화
- [ ] 값은 추측 불가능한 랜덤 문자열(예: 32바이트 이상)로 생성

> **이유**: 서비스 간 내부 호출을 검증하는 공유 비밀입니다. 개발용 기본값을 그대로 쓰면
> 누구나 아는 값이 되어 내부 API를 임의 호출할 수 있습니다. 두 서비스의 값이 다르면 정상 호출이 막히므로
> 반드시 같은 값으로 맞춰야 합니다.

---

## 3. Actuator 노출 제한 (H-N2 / H-A)

- [ ] 운영에서 actuator 관리 포트를 서비스 포트와 분리하거나, 내부망에서만 접근 가능하게 제한
- [ ] `/actuator/**` 엔드포인트가 외부에 열려 있지 않은지 확인

> **이유**: actuator는 헬스체크·환경변수·메트릭 등 내부 정보를 노출할 수 있습니다.
> 외부에 열려 있으면 서버 구성 정보가 유출될 수 있으므로 관리 포트를 분리하거나 내부망으로 한정합니다.

---

## 4. 자격증명 환경변수 주입 (평문 금지)

- [ ] MinIO 접속 키/시크릿을 환경변수로 주입 (설정 파일에 평문 저장 금지)
- [ ] DB 사용자/비밀번호를 환경변수로 주입
- [ ] Redis 비밀번호를 환경변수로 주입
- [ ] Kafka 접속 정보(필요 시 SASL 자격증명)를 환경변수로 주입

> **이유**: 자격증명을 코드나 설정 파일에 평문으로 두면 저장소·이미지 유출 시 그대로 노출됩니다.
> 운영 값은 환경변수(또는 시크릿 매니저)로 주입해 저장소에 남기지 않습니다.

---

## 5. CORS 허용 오리진 지정

- [ ] `allowed origin` 을 실제 서비스 도메인으로 명시 (와일드카드 `*` 금지)
- [ ] `allowCredentials=true` 와 와일드카드를 함께 쓰지 않도록 확인

> **이유**: 쿠키 기반 인증(`allowCredentials=true`)에서는 오리진을 와일드카드로 열 수 없습니다.
> 와일드카드를 허용하면 임의 사이트에서 사용자 쿠키를 실은 요청을 보낼 수 있어 CSRF 위험이 커집니다.
> 실제 도메인만 화이트리스트로 등록합니다.

---

## 6. HTTPS 및 refresh 쿠키 Secure 설정

- [ ] 운영에 HTTPS 적용
- [ ] `app.cookie.secure=true` 로 refresh 쿠키의 `Secure` 속성 활성

> **이유**: `Secure` 속성이 켜지면 쿠키가 HTTPS 연결에서만 전송됩니다. HTTP로 평문 전송되어
> 중간에서 refresh 토큰이 탈취되는 것을 막습니다. HTTPS 미적용 상태에서 `Secure=true`를 켜면
> 쿠키가 전송되지 않으므로, HTTPS 적용과 함께 활성화합니다.
